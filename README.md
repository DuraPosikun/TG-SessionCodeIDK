# TG Code Bot — вход по tdata / session и получение кода

Бот в Telegram: пользователь кидает ему **tdata** (zip/7z/rar) или **session-файл** (`.session`, `session.json` со строкой сессии), бот входит в аккаунт и присылает «✅ Вход успешный» с номером. Затем по кнопке «📨 Запросить код» бот запрашивает код входа и пересылает сообщение Telegram («Код для входа в Telegram: 12345…») **1в1** в чат — чтобы владелец чата мог войти в аккаунт просто по номеру, без файлов.

## Как это работает

```
Ты ─ tdata.zip / session.json ─▶ Бот
Бот ─ «✅ Вход успешный» + номер + [📨 Запросить код] ─▶ Ты
Ту � нажатие кнопки
Бот �▶ запрашивает код на аккаунте (через сессию)
Telegram (777000) ─▶ «Код для входа в Telegram: 12345. Не давайте его никому…»
Бот копирует это сообщение 1в1 ─▶ Ты
```

## Установка

1. Python **3.9+** (проверено на 3.14; для конвертации tdata opentele2 использует `tgcrypto-pyrofork` — готовые wheels, компилятор не нужен).
2. Получи `API_ID` и `API_HASH` на [my.telegram.org](https://my.telegram.org) → **API development tools**.
3. Создай бота у [@BotFather](https://t.me/BotFather) → скопируй токен.
4. Скачай/скопируй файлы проекта в папку, затем:

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
pip install -r requirements.txt
```

> Если `opentele2` не ставится — установи без него (`pip install py7zr rarfile python-dotenv telethon`): тогда сессии (`*.session` / `session.json`) работать будут, а tdata — нет.

5. Скопируй `.env.example` в `.env` и заполни `API_ID`, `API_HASH`, `BOT_TOKEN`.
6. Запуск:

```bash
python bot.py
```

## Использование

1. `/start` в чате с ботом.
2. Пришли файл:
   - архив с **tdata** (zip / 7z / rar — внутри должна быть папка `tdata` или её файлы: `key_ds`, `usertag`, `map`…);
   - **`.session`** файл (Telethon);
   - **`session.json`** (или txt) со строкой сессии Telethon (`{"session": "1BANa..."}`) — можно и просто строку сессии сообщением.
3. Бот отвечает «✅ Вход успешный» + номер аккаунта, либо «🚫 Вход не успешный» с причиной (невалидный файл).
4. Жми **📨 Запросить код** → бот (если получится) запрашивает код через сессию и включает пересылку: **все** сообщения от Telegram (777000) приходят в чат 1в1, пока сессия активна.
5. `/stop` — отключить сессию и удалить файлы.

## Команды

**Для всех** (видны в /start):
- `/profile` — профиль: username, ID, лимит (0/10) и подсказка, как его поднять;
- `/support` — создать тикет; следующее сообщение уйдёт админу (с твоим ID и username);
- `/converter` — конвертация в tdata: пришли архив (zip/7z/rar) с `.session` / `session.json` — бот вернёт tdata-архив;
- `/proxy` — прокси-система: пришли `.txt` (по прокси в строке) или текстом — все виды: `socks4`/`socks5`/`http`/`https`, IPv4/IPv6, форматы `socks5://user:pass@host:port`, `host:port:user:pass` и т.п. Входы в твои аккаунты пойдут через твой прокси-пул; если он пуст — без прокси. Сбитые прокси отключаются автоматически (3 сбоев). У каждого юзера свой пул: `/proxy list` — посмотреть, `/proxy del ID` — удалить прокси, `/proxy clear` — очистить пул;
- `/stop` — отключить сессию.

**Промокоды** (в /start не видна):
- `/promo КОД` — активировать промокод: +N к лимиту, 1 промокод = 1 активация на аккаунт.

**Админка** (доступна только `ADMIN_ID` из `.env`):
- `/tryadmin` — открыть панель: 📢 Рассылка, 👤 Статистика, 🎟 Создать промокод (формат: `КОД использований прибавка`, напр. `FUN10 100 1`), ⚙ Настройки;
- `/setlimit N` — дефолтный лимит новым юзерам;
- `/setmsg текст` — сообщение при исчерпании лимита (по умолчанию «У вас закончился лимит»);
- `/setuserlimit ID N` — изменить лимит конкретному юзеру;
- `/ban ID 12h|3d|perm причина` — бан в боте (юзер увидит «Вы заблокированы в боте»);
- `/bansupport ID 12h|3d|perm причина` — запрет на /support (юзер увидит «Вам запрещен доступ к этой команде» + причина);
- `/unban ID`, `/unbansupport ID` — снять блокировки;
- ответ на пересланное сообщение тикета = ответ юзеру; кнопка «🔒 Закрыть тикет» закрывает его.

Лимит расходуется за каждый успешный вход (загрузку файла). При исчерпании — настраиваемое сообщение. Вся статистика (юзеры, баны, промо, входы) — в 👤 Статистика админки.

## Автовход при старте (без отправки файла)

Чтобы бот сам зашёл по сессии сразу после запуска, заполни в `.env`:

- `ADMIN_ID` — твой chat id (узнай у @userinfobot), куда бот пришлёт «✅ Вход успешный» с кнопкой;
- `STARTUP_SESSION` — строка сессии Telethon, либо путь к `session.json`/`*.session`;
- или `STARTUP_TDATA` — путь к папке `tdata` либо архиву (zip/7z/rar) с ней.

Приоритет: `STARTUP_SESSION`, если он пуст — `STARTUP_TDATA`. Кнопка «📨 Запросить код» работает и для автовхода; `/stop` отключает сессию автовхода.

## Заметки

- Если бот не смог запросить код (флуд-лимит Telegram), просто войди по номеру со своего устройства — код придёт в аккаунт, и бот его перешлю (пересылка уже включена после нажатия кнопки).
- На аккаунте с 2FA код придёт, но для завершения входа понадобится ещё и пароль 2FA — это на стороне того, кто входит.
- Файлы пользователей хранятся в `data/<user_id>/` и удаляются после проверки; `/stop` тоже чистит.
- `ALLOWED_IDS` в `.env` — ограничь доступ ботом только своими ID (пусто = доступ для всех).
- Репозиторий не хранит ключи — но `data/` содержит рабочие сессии бота: не публикуй её.

## Дисклеймер

Используй только со своими аккаунтами или с явного согласия владельца. Доступ к чужим аккаунтам без разрешения — незаконен.
